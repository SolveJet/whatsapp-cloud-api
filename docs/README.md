# Documentation

Guides for `@solvejet/whatsapp-cloud-api`. The main reference is the
[project README](../README.md).

## API guides

- [Error handling](./errors.md): the error class hierarchy, retries, and how to branch on Graph error codes.
- [Template management](./templates.md): create, list, read, edit, and delete message templates.
- [Flows management](./flows.md): build and manage WhatsApp Flows.
- [Block API](./blocks.md): block, unblock, and list users.
- [Calling](./calling.md): calling settings and the call lifecycle.
