# Support

This SDK is an independent project. It is not affiliated with or endorsed by Meta or WhatsApp. Community support is provided by volunteers and has no SLA.

## Usage questions

1. Search the [README](README.md) and the `examples/` directory.
2. If you still need help, ask in [GitHub Discussions, Q&A](https://github.com/SolveJet/whatsapp-cloud-api/discussions/categories/q-a).

## Ideas and showing your work

- Share ideas in [Ideas](https://github.com/SolveJet/whatsapp-cloud-api/discussions/categories/ideas).
- Show what you built in [Show and tell](https://github.com/SolveJet/whatsapp-cloud-api/discussions/categories/show-and-tell).

## Bugs and feature requests

Use the [issue templates](https://github.com/SolveJet/whatsapp-cloud-api/issues/new/choose) for bugs and concrete feature requests.

## Security vulnerabilities

Report them privately through a [security advisory](https://github.com/SolveJet/whatsapp-cloud-api/security/advisories/new). Never open a public issue. See [SECURITY.md](SECURITY.md).

## Code of conduct

Send conduct reports to hello@solvejet.net. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## WhatsApp Business Platform issues

Problems with the platform itself, such as accounts, number verification, template approval, billing, or bans, cannot be resolved here. Contact Meta support.
